# UAT Test Cases - ICEGATE SCMTR Open API Integration

Environment: **ICEGATE UAT** (`Icegate:Environment = UAT`). Run these against the Postman
collection in `postman/ICEGATE_SCMTR_UAT.postman_collection.json`, folder
"2. Our API (Icegate.Integration .NET 8)", unless a test case says "direct to ICEGATE".

Legend for **Expected Application Status** = the `TransactionStatus` recorded on the
`ICEGATE_API_TRANSACTION` row for that operation.

## Execution notes

- Tests that require ICEGATE to return an artificial failure (TC08, TC19, TC20, TC22) may
  need a local mock/stub of the ICEGATE endpoints if UAT cannot be coerced into that state on
  demand - point `Icegate:*Url` settings at the mock for that run only, then restore the real
  UAT URLs.
- For TC10, coordinate with ICEGATE UAT support on what constitutes a "duplicate" (same
  `uniqueId` re-submission vs. same business content) before relying on a specific message.
- Every test case should assert `correlationId` is present and non-empty on the response, and
  that the `ICEGATE_API_TRANSACTION` row for the run has `Environment = UAT`.
- Never run these test cases with production ICEGATE credentials or production URLs.
